معماری مهندسی

زیر هود پنل Dev.Cop چه می‌گذرد؟

طراحی‌شده برای کارایی حداکثری روی بستر ایزوله V8 Workers کلودفلر با استاندارد‌های رمزنگاری نوین.

01

پروتکل‌ها و تونلینگ

  • VLESS و Trojan روی بستر ایمن WebSocket
  • رله‌ی UDP کامل برای گیمینگ، تماس تصویری و DNS
  • پشتیبانی از زنجیره پروکسی خروجی SOCKS5 / HTTP
02

امنیت و کنترل دسترسی

  • رمزگذاری رمزعبور با SHA-256 و کوکی‌های امضاشده HMAC
  • قفل امنیتی ضد Brute-force روی صفحه ورود پنل
  • ایمن‌سازی کامل API با قفل Origin و فیلتر CSRF
03

ضد فیلترینگ و استتار DPI

  • تکه‌تکه‌سازی بسته (Fragment) و TLS Masking
  • پریست‌های سازگار با الگوهای Patterniha (PattNG)
  • استتار هدرهای هندشیک منطبق با مرورگر کروم
04

دیتابیس ابری توزیع‌شده D1

  • دیتابیس بدون سرور Cloudflare D1 (SQLite Edge)
  • پشتیبان‌گیری کامل با یک کلیک (JSON Export / Import)
  • همگام‌سازی لحظه‌ای سهمیه کاربران در سراسر دنیا
05

رابط کاربری و دسترس‌پذیری

  • کامپوننت‌های بومی فارسی با چیدمان RTL-First
  • پشتیبانی از PWA و حالت آفلاین با کش مرورگر
  • رعایت کامل استانداردهای رنگی و prefers-reduced-motion
06

استقلال و شفافیت سورس

  • ۱۰۰٪ سورس مستقل و بدون کد مخفی یا تله
  • سازگار با بررسی سلامت کدهای کلودفلر check:cf
  • مالکیت تمام و کمال زیرساخت روی حساب شخصی خودتان

پاسخ به ابهامات

سوالات متداول

دقیقاً همینطور است. پنل به صورت کدهای بدون سرور (Serverless) روی Cloudflare Workers و دیتابیس ابری Cloudflare D1 اجرا می‌شود. دامنه رایگان با ساب‌دامین workers.dev به شما تعلق می‌گیرد و هیچ هزینه‌ای بابت سرور، لایسنس یا دامنه پرداخت نمی‌کنید.

پلن رایگان Cloudflare Workers روزانه ۱۰۰,۰۰۰ درخواست را به رایگان پردازش می‌کند که برای مدیریت ده‌ها کاربر و مصرف مداوم خانگی و دوستانه کاملاً کافی است. مصرف دقیق شما هم به صورت شفاف در داشبورد پنل نمایش داده می‌شود.

توکن کلودفلر فقط در همان لحظه استقرار توسط ربات تلگرام برای ساخت D1 و Worker استفاده شده و به هیچ وجه روی دیسک ذخیره نمی‌شود. تمام رمزهای عبور پنل با الگوریتم SHA-256 هش می‌شوند و سشن‌ها دارای امضای دیجیتال HMAC هستند.

لینک اشتراک Dev.Cop هوشمند است و با تشخیص کلاینت، کانفیگ را با فرمت متناسب تحویل می‌دهد: فرمت Base64 برای v2rayNG و Hiddify، فرمت JSON برای sing-box و Xray، و فرمت YAML برای نرم‌افزارهای خانواده Clash.

خیر. داده‌های کاربران، حجم‌ها و زمان انقضا در دیتابیس جداگانه D1 نگهداری می‌شوند. با هر بار آپدیت کردن ورکر یا تغییر آدرس، دیتابیس دست‌نخورده باقی می‌ماند. همچنین می‌توانید در هر لحظه یک نسخه پشتیبان کامل JSON از پنل دانلود کنید.
