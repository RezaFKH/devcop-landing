# Dev.Cop Panel — Official Landing Page

> لندینگ‌پیج رسمی و مدرن پنل مدیریت پروکسی Dev.Cop روی بستر Cloudflare Workers و دیتابیس D1.

## 🚀 ویژگی‌های کلیدی صفحه (Key Features)

- **طراحی مدرن و مهندسی‌شده**: بر پایه دیزاین‌سیستم اختصاصی نئون-اسپکتروم با پشتیبانی کامل از تم روشن (Light) و تاریک عمیق (Dark Titanium).
- **موشن‌دیزاین و نورپردازی پویا**:
  - سیستم اسپات‌لایت ماوس روی کارت‌ها (Spotlight Mouse Lighting) مشابه رابط‌های کاربری Linear و Vercel.
  - هسته وکتور شیلد سه‌بعدی تعاملی با افکت ژیروسکوپ زاویه‌دار (3D Tilt Core).
  - کانواس متحرک شبکه لبه توزیع‌شده کلودفلر (Global Edge Network Canvas).
- **ویجت‌های تعاملی زنده**:
  - **ماک‌آپ زنده پنل وب (Live Panel Web UI Mockup)**: پیش‌نمایش ۴ تب اصلی پنل (داشبورد، کاربران، آی‌پی تمیز و ضد فیلتر).
  - **آزمایشگاه کلاینت و کانفیگ (Live Subscription Playground)**: تولید آنی لینک، QR Code و کانفیگ تست برای v2rayNG، Hiddify، sing-box، Clash و Streisand.
  - **شبیه‌ساز تعاملی ربات تلگرام (Bot Chat Simulator)**: کلیدهای شیشه‌ای تعاملی با پاسخگویی آنی ربات.
  - **محاسبه‌گر صرفه‌جویی هزینه سرور (VPS Cost Savings Calculator)**: اسلایدر محاسبه مقدار دلاری و تومانی صرفه‌جویی در هزینه سرور.
  - **پالت فرمان سریع (`Ctrl+K`)**: جستجو و پرش سریع به بخش‌های صفحه و دستورات کلیدی.
  - **جستجو در سوالات متداول (FAQ Search & Filter)**: فیلتر آنی بر اساس دسته‌بندی و واژه‌های جستجو شده.
- **تایپوگرافی اصیل و RTL-First**: فونت بهینه‌شده وزیرمتن، نگارش بدون غلط، کرنینگ دقیق و اعداد اصیل فارسی.
- **عملکرد و دسترس‌پذیری**: رندرینگ سبک تک‌فایلی (Single-File)، صفر وابستگی خارجی سنگین، ۶۰ فریم بر ثانیه، و پایبندی کامل به `prefers-reduced-motion`.
